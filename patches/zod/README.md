# Pinned Zod maintainer security backport

Source: https://github.com/colinhacks/zod/commit/a0ebf970f2d752e5f58527cd2942ff48be4f46bd

Advisory: https://github.com/advisories/GHSA-mrhx-c7xc-m3w5

The registry available to this project publishes 4.6.5, while the advisory identifies
4.6.6 as patched. This directory vendors the exact maintainer patch and MIT license;
it does not invent a package version, hide the advisory, or authorize a release.

`scripts/apply-zod-security-backport.mjs` applies only the three upstream core source
changes, after verifying original source and patch checksums. It regenerates their
ESM and CommonJS runtimes using the repository's pinned TypeScript compiler. Every
generated byte is pinned in `manifest.json`; unknown package versions, modified
sources or unexpected compiler output fail installation. No code is fetched during
installation. `--check` verifies the installed source and both runtime formats.

The security regressions exercise interpreted, compiled and asynchronous parsing,
including arrays, maps, sets and transformation ordering. Unbounded schemas still
need appropriate application input limits; this is the upstream constrained-size fix.

Raw `npm audit` continues to identify the published package version as affected.
The existing audit gate is intentionally retained. A published fixed release or an
explicitly reviewed backport acceptance is still needed before that release gate can
pass. When adopting the official patched version, remove this backport and its install
hook only after the same regressions and application checks pass.
